# TouchWood — Site

This is the frontend for the TouchWood Interior AI project, built with TanStack Start, React, and Tailwind CSS.

## Getting Started

```bash
cd site
npm install
npm run dev
```

The dev server starts at `http://localhost:3000` by default.

## Project Structure

- `src/routes/` — TanStack file-based routes
- `src/components/` — Shared UI components (Radix/shadcn-based)
- `src/lib/` — Utilities and helpers
- `src/styles.css` — Global CSS / Tailwind tokens
